# 侧边栏与主题情报流设计

## 目标

将网站升级为侧边栏驱动的 AI 情报站。首页继续使用统一新闻时间线，同时通过内容分类、模型实体、技术主题和证据等级帮助用户快速定位官方发布、实践方法、开源工具、研究论文与行业动态。

## 数据来源

来源分为三层：

1. 原始来源：公司博客、个人博客、论文 RSS、GitHub Release。
2. 发现来源：AI HOT 匿名只读 API，用于发现 X 实践账号、官方社交账号和其他公开动态；每条内容保留第三方原文链接及 AI HOT 署名。
3. 社区来源：Hacker News、Hugging Face 等，作为发现线索并降低默认可信度。

第一阶段新增 AI HOT 过去 24 小时精选、Simon Willison、One Useful Thing、Latent Space、Import AI、The Decoder 和 GitHub AI Blog。X 官方 API 接口保留配置位，但不要求新密钥。

## 内容分类

主分类：模型、产品、Agent 与编程、实用技巧、开源、研究、政策、商业、人物观点、其他。

内容类型：官方发布、实践方法、开源项目、研究论文、实测对比、行业新闻、人物观点。

主题标签：由 DeepSeek 从标题和摘要生成，最多 8 个。

模型实体：GPT、Codex、Claude、Gemini、DeepSeek、Qwen、Kimi、GLM、Llama、Grok 等，最多 6 个。

证据等级：

- primary：官方、作者本人、项目仓库或论文原文。
- verified：多个独立来源或有可复现材料。
- practitioner：个人实测、教程或操作方法。
- unverified：单一观点或尚未验证的说法。

## 评分

保留 1–100 综合分，DeepSeek 同时考虑：可操作性、新颖度、证据、作者可信度和多源印证。实践内容包含明确步骤、配置、代码或仓库时提高评分；纯营销、无出处转发和无法验证的夸大表述降低评分。

## 页面结构

桌面端使用固定左侧栏：

- 首页
- 最新动态
- 今日精选
- 模型动态
- AI 产品
- Agent 与编程
- 实用技巧
- 开源项目
- 研究论文
- 政策监管
- 商业融资
- 人物观点
- 收藏

每个菜单项显示当前窗口内的数量。侧边栏底部显示最后更新、DeepSeek 状态与成功来源数。移动端使用顶部菜单按钮打开抽屉式侧边栏。

主区域保留统一新闻时间线。条目依次显示时间、来源、内容类型、标题、摘要、为什么重要、模型/主题标签、证据等级和原文链接。所有条目版式相同，默认按发布时间倒序。

## 聚合与筛选

侧边栏按主分类筛选；模型与主题标签进行第二层筛选。同一条内容可以出现在一个主分类和多个模型或主题入口中。搜索覆盖中文标题、摘要、来源、主题与模型。

## 可靠性规则

- 官方与作者原帖可直接进入候选池。
- 实践方法必须具有步骤、配置、代码、仓库、演示或清晰经验描述之一。
- 传闻和重大数字若没有原始链接或第二来源，只能标记未验证，不能进入今日精选。
- AI HOT 只作为发现与摘要来源，页面保留“数据来源：AI HOT”和第三方原文入口。
- 同一事件继续按链接和标题相似度合并。

## 验收标准

- 首页为统一时间线，桌面端有固定侧边栏，手机端无横向溢出。
- 菜单分类、模型标签、主题标签、搜索、来源和排序筛选均工作。
- AYI 的 Codex 实践内容能够通过 AI HOT API 进入候选池，并链接到 X 原帖。
- 每条新内容具有 contentType、topics、models、evidenceLevel 字段。
- 原有 11 个来源继续工作，新增来源失败不阻断其他来源。
- 自动任务完成后自动部署网站，测试和真实云端运行通过。
