# 主题归类与大模型官网入口设计

日期：2026-08-17

## 目标

修复主题地图依赖自由文本搜索导致的错放、漏放和计数不一致；重新扫描现有新闻，为公司模型、技术方向和内容形态生成稳定的主题索引。同时把“模型排名”入口移动到首页侧边栏“今日精选”下方，并在每个公司/大模型卡片中增加经过核对的官网入口。

成功标准：

- Qwen、MiniMax 等模型家族不会因 `Max` 等局部字符串互相误判。
- 一条真正涉及多个模型的新闻可以进入多个主题；摘要顺带提到的竞品不进入竞品主题。
- 主题卡片数量与点开后的新闻数量一致。
- 新抓取新闻会自动进入正确主题，不需要手工维护。
- 每个公司/模型卡片同时提供“查看本站情报”和“打开官网”两个独立入口。
- 首页侧边栏中“模型排名”紧跟“今日精选”。

## 方案选择

采用统一主题索引方案。相比手工改数据或仅改前端搜索，它能让计数、筛选和自动更新共享同一套规则，同时不修改新闻正文或翻译内容。

## 主题分类架构

新增独立的主题分类模块，维护每个主题的稳定 ID、名称、别名、匹配规则和官网链接。分类模块只负责回答“这条新闻属于哪些主题”，不负责页面渲染。

### 公司与模型主题

使用强信号归类：

1. 新闻的结构化 `models` 字段出现该模型或其明确版本名。
2. 新闻标题明确出现公司、模型家族或产品名。
3. 新闻来自该公司或产品的官方来源；官方来源由现有 `sourceId` 白名单映射，不使用名称模糊匹配。
4. 只有在以上信号都不存在时，才允许用主题标签中的完整品牌名补充归类。

摘要正文不作为普通匹配来源，避免对竞品、历史背景和顺带提及产生误判。

允许多主题归类。例如标题明确比较 Qwen 与 MiniMax 时同时进入两个主题；只讨论 Qwen3.8-Max 时不得因 `Max` 后缀进入 MiniMax。MiniMax 仅匹配完整的 `MiniMax`、`Mini Max` 或明确官方来源。

### 技术方向主题

技术方向以结构化 `topics`、`keywords`、`category` 和 `contentType` 为主，使用明确别名表归一化，例如：

- Agent 智能体：Agent、智能体、工具调用、多智能体。
- AI 编码：AI coding、代码生成、编程代理、Codex、Claude Code。
- 多模态：multimodal、多模态、视觉语言模型。
- 安全对齐：alignment、AI safety、越狱、红队、安全评测。

技术主题允许多选，但不依赖宽泛单字或容易重叠的缩写。

### 内容形态主题

内容形态优先使用已有结构化字段：

- 模型发布：`category=models` 且内容为发布、版本或权重更新。
- 产品更新：`category=products` 或产品功能发布。
- 论文研究：`contentType=paper`。
- 评测基准：`contentType=benchmark` 或明确 benchmark 主题。
- 教程实践：`category=tips` 或 `contentType=practical`。
- 大佬观点：`category=opinion` 或 `contentType=opinion`。
- 政策监管：`category=policy`。

## 数据流

每次新闻抓取完成后，分类模块扫描当前新闻索引并生成 `data/topic-index.json`。文件记录生成时间、每个主题的新闻 ID、精确数量和无法归类的审计信息。

主题地图读取该索引展示数量；卡片链接使用稳定参数 `index.html?theme=qwen`。首页读取同一索引并按新闻 ID 过滤，不再把卡片展示名称当作搜索词。

现有新闻通过一次完整扫描立即生成主题索引，不回写新闻正文，也不批量修改历史 JSON。后续每次自动抓取都会重建索引，因此新模型版本能随新闻自动出现。

若 `topic-index.json` 暂时读取失败，首页保留普通新闻时间线，主题页显示明确的“主题索引暂不可用”提示，不退回可能产生错放的模糊搜索。

## 大模型官网入口

公司与模型卡片改为普通卡片容器，内部包含两个不嵌套的链接：

- 主链接：“查看本站情报”，进入对应主题新闻。
- 次链接：“官网 ↗”，新标签页打开官网并使用 `rel="noopener noreferrer"`。

## 导航调整

首页侧边栏顺序调整为：

1. 首页
2. 最新动态
3. 今日精选
4. 模型排名
5. 分类栏目

主题地图、归档和模型排名独立页面仍保留模型排名入口，但不重复伪造“今日精选”按钮。

## 测试与审计

自动测试覆盖：

- `Qwen3.8-Max` 只进入 Qwen，不进入 MiniMax。
- `MiniMax-H3` 只进入 MiniMax。
- 标题明确比较 Qwen 与 MiniMax 时进入两个主题。
- 摘要顺带提到竞品时不产生额外公司主题。
- 官方来源可以补充没有品牌标题的产品新闻。
- 主题计数等于主题新闻 ID 数量，且 ID 不重复。
- 所有公司/模型卡片拥有有效的 HTTPS 官网链接。
- 首页能通过 `theme` 参数展示索引中的精确新闻集合。
- 桌面和手机端的两个卡片入口均可点击，移动菜单和侧边栏顺序正确。

发布前输出一次主题审计摘要，列出每个主题数量、未归类新闻数量和可能包含多个模型的新闻，便于人工抽查。
