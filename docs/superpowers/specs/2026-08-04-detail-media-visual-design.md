# 详情页媒体与数据图表设计

## 目标

让读者尽量在中文详情页理解一条新闻，而不必立刻打开英文原文。原文带有可识别图片或图表时展示它们；原文只给出明确数字对比时，用中文横向条形图整理；没有可靠数据时不生成图表。

## 规则

- RSS 的 HTML 图片、`media:content`、缩略图和 AI HOT 媒体字段统一提取，最多保留 8 张，详情页懒加载展示。
- 图片保留原始 URL，不下载、不重绘、不修改原图；图片失效时自动隐藏，不影响详情阅读。
- DeepSeek 输出可选 `visual` 结构：`bar`、`comparison`、`metrics`、`line` 或 `none`，只接受至少两个明确的数值点。
- 图表点位必须有标签和数值，数值来源于输入文本；缺少两个可比点时强制不展示。
- 页面明确标注“根据原文明确数字整理”，避免把启发式热度图和事实图表混淆。

## 验收标准

- 含 `<img>` 或媒体字段的 RSS 项目能把图片 URL 写入事件并在详情页展示。
- 数值点不足两个、字段非法或类型为 `none` 时，图表区域隐藏。
- 手机视口下图片、图表不溢出，仍能点击原文链接。
