# 统一新闻时间线 UI 设计

## 目标

将首页改为没有头版、排行或数据仪表盘的统一新闻时间线。页面首先服务于快速阅读：最新新闻在前，每条新闻使用完全相同的结构，标题突出、内容紧随其后。

## 删除内容

- 删除首页超大焦点标题及焦点新闻模块。
- 删除热点排行模块。
- 删除“最新收录、重点新闻、最后更新、下次抓取”四项指标及其容器。
- 删除由重要度决定尺寸、位置或版式的视觉层级。

## 页面结构

1. 紧凑顶部导航：品牌、今日、模型、产品、商业、研究、政策。
2. 页面说明栏：当前日期和最后一次数据更新时间，仅作为一行辅助信息，不使用指标卡片。
3. 筛选栏：搜索、分类、来源和排序控件。
4. 新闻时间线：全部新闻按新闻发布时间倒序排列。
5. 页脚：版权说明。

## 时间线条目

所有条目使用同一模板和尺寸，固定顺序为：

1. 时间节点：相对时间和准确发布时间。
2. 元数据：来源、分类和重要度文字标签。
3. 中文标题：条目中最醒目的元素，使用加粗衬线字体。
4. 中文摘要：紧接标题之后完整展示。
5. 为什么重要：作为次级说明。
6. 操作：原文链接、收藏、标为已读。

桌面端时间轴位于左侧，时间节点通过纵向连接线串联；正文位于右侧。手机端仍保留时间线，但缩短左侧空间，并将时间与元数据放在标题上方。

## 排序与筛选

- 页面初始状态固定按 `publishedAt` 倒序，即新闻真实发布时间最新的靠前。
- 用户可切换为按重要度排序，但不改变条目视觉格式。
- 搜索、分类和来源筛选沿用现有数据与即时更新行为。
- 分类按钮显示当前分类和新闻数量，但不展示额外趋势关键词栏。

## 视觉规则

- 保留米白背景、深色文字和橙色强调色。
- 不使用大面积黑色排行卡片和指标卡片。
- 时间轴线使用低对比度灰色，当前节点使用橙色圆点。
- 标题明显大于摘要；摘要明显大于来源、时间和操作文字。
- 重要度仅显示“重大”“值得关注”或“一般动态”小标签，不影响排序以外的版式。
- 所有条目之间使用一致间距和分隔规则。

## 状态处理

- 没有数据时，在时间线位置显示首次抓取提示。
- 数据陈旧或来源失败时，在说明栏下方显示单行警告，不恢复指标卡片。
- 未生成中文内容时显示中文处理提示，不以英文正文填充。

## 验收标准

- 首屏不出现焦点大标题、热点排行或四项指标。
- 所有新闻以相同格式展示，默认按 `publishedAt` 倒序。
- 每条新闻按“时间与来源 → 突出标题 → 摘要 → 为什么重要 → 原文链接”的顺序阅读。
- 时间轴在桌面端和手机端连续、清楚且没有横向溢出。
- 搜索、分类、来源、排序、收藏、已读和原文链接继续正常工作。
- 页面脚本无控制台错误，现有数据处理测试全部通过。
