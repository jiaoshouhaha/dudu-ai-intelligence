# 主题归类与官网入口实施计划

1. 新增 `src/lib/topic-taxonomy.mjs`：定义公司模型、技术方向和内容形态主题；实现强信号、多主题与去重归类；维护公司模型官网和官方来源 ID 白名单。
2. 新增主题分类测试：覆盖 Qwen3.8-Max、MiniMax-H3、Qwen/MiniMax 对比、摘要顺带提及、官方来源补充、主题 ID 去重和官网 HTTPS 校验。
3. 扩展 `src/lib/storage.mjs`：每次新闻数据写入时从当前首页新闻生成 `data/topic-index.json`，输出主题元数据、精确新闻 ID、数量和审计摘要。
4. 新增 `scripts/build-topic-index.mjs` 与 package 脚本：无需重新抓取新闻即可重建现有 240 条新闻的主题索引，并输出各主题数量、多模型新闻和未归类数量。
5. 重构 `public/topics.js`：读取统一主题索引渲染卡片；公司模型卡片提供“查看本站情报”和“官网”两个独立链接；失败时显示明确错误，不回退自由文本搜索。
6. 更新 `public/app.js`：识别 `theme` 查询参数，读取主题索引并按新闻 ID 精确筛选；主题标题、结果数量和清除筛选保持同步。
7. 更新 `public/topics.css`：适配双链接卡片的桌面和手机布局，确保官网链接有独立可点击区域和键盘焦点。
8. 调整 `public/index.html`：把“模型排名”从“浏览”组移动到“今日精选”正下方；保持其他独立页面导航不变。
9. 执行现有新闻回填并人工审计公司模型主题，重点抽查 Qwen、MiniMax、Kimi、GLM、Grok 和多模型比较新闻。
10. 运行语法检查、全部单元测试和 Playwright 桌面/手机验证：检查主题数量与筛选结果一致、双入口可点击、侧边栏顺序正确且无横向溢出。
11. 提交并推送 GitHub，等待 GitHub Pages 部署成功，在线验证主题地图、Qwen/MiniMax 分类、官网链接和模型排名位置。
