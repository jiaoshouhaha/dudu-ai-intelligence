# AI 新闻情报站实施计划

## 阶段 1：项目与数据契约

- 建立零框架静态前端与 Node.js 数据流水线。
- 定义来源配置、新闻记录、索引、趋势和状态数据结构。
- 提供 `.env.example`，保留兼容 OpenAI 协议的模型配置。

## 阶段 2：抓取与处理

- 实现 RSS/Atom 解析、字段清理和 URL 规范化。
- 实现跨来源去重、来源合并和稳定事件 ID。
- 实现透明的规则评分与评分理由。
- 实现可选 AI 增强适配器及严格输出校验。
- 实现日期分片、首页索引、搜索索引、趋势和状态生成。

## 阶段 3：网站

- 实现编辑部头版响应式首页。
- 实现双语切换、搜索、分类/来源筛选、排序和来源展开。
- 实现收藏、已读状态、状态提示和无数据引导。
- 提供本地静态服务器与示例数据。

## 阶段 4：自动化

- 建立每小时第 17 分钟运行的 GitHub Actions 工作流。
- 配置并发保护、手动触发、数据变更自动提交和 Secrets 接口。
- 加入模型调用数量、并发和超时保护。

## 阶段 5：验证

- 使用 Node 内置测试运行器验证解析、去重、评分、AI 降级和输出。
- 执行真实 RSS 抓取并验证生成数据。
- 在桌面和移动尺寸验证页面功能和视觉布局。
- 完成无密钥与工作流配置审计。
