# 可靠新闻发现与六个月情报档案实施计划

## 1. 管线与数据

- 给来源配置增加优先级与每轮条数上限，并加入 Qwen 官方 release feed。
- 在抓取、去重和候选选择中传递来源优先级，增加模型实体跨语言去重和重大事件优先通道。
- 将存储改为 180 天按日期分片，同时生成月份/日期归档索引。
- 为事件生成可解释的报道时间线和热度估算数据，并写入现有 index/search 数据。

## 2. 前端

- 修复全局 `hidden` 样式，保证移动遮罩不会覆盖页面。
- 扩展详情页：事件全貌、热度走势、报道时间线、原文链接。
- 新增归档页和主题地图页，补充侧边栏入口并支持移动布局。

## 3. 调度与验证

- GitHub Actions 调整为每 30 分钟运行，单轮上限降为 12，保留手动触发。
- 更新单元测试，执行 `pnpm test`、`git diff --check`，用本地页面检查移动端链接。
- 提交、拉取变基、推送，手动触发 workflow，确认 Qwen 等重大事件覆盖与 Pages 部署状态。
